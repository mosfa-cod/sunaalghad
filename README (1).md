## ⚙️ خطوة واحدة لتفعيل استقبال الطلبات

### 1. سجّل في Formspree مجاناً
👉 https://formspree.io/register

### 2. أنشئ فورم جديد
- اضغط **+ New Form**
- اسمه: `مدرسة صناع الغد`
- انسخ الـ **Form ID** (مثال: `xpzgkwrb`)

### 3. عدّل سطر واحد في index.html
```html
<!-- ابحث عن هذا السطر -->
action="https://formspree.io/f/YOUR_FORM_ID"

<!-- واستبدل YOUR_FORM_ID بالـ ID بتاعك -->
action="https://formspree.io/f/xpzgkwrb"
```

### 4. ارفع index.html المعدّل
وبس! كل طلب تسجيل هيوصلك على إيميلك فوراً 📧
